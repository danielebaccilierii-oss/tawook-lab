# Tawook Lab — Website Demo

Single-page static website demo for **Tawook Lab**, Syrian charcoal kitchen with two locations in central Helsinki.

- One self-contained `index.html` (inline CSS/JS, no build step)
- Photography in `assets/`
- Google Fonts

## Preview locally

Open `index.html` in a browser, or run `python -m http.server 8000` in this folder.
